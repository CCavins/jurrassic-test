# Asset research

Legal clarity was treated as more important than photoreal fidelity.

## Chosen: Quaternius Animated Dinosaur Bundle (CC0)

- License: CC0 / public domain
- Quality: stylized low-poly, consistent across all six required species
- Animation: Idle, Attack, Walk, Run, Jump, Death on each model
- Mobile: 279–413 KB GLB each, 1 mesh per model, 2–5 materials
- Status: **chosen and shipped**
- Reason: only complete six-species set with rigs, animation, GLTF, and an unambiguous commercial license

Sources used:

- https://poly.pizza/bundle/Animated-Dinosaur-Bundle-SmoLdBLO2K
- https://quaternius.itch.io/animated-lowpoly-dinosaurs
- Individual Poly Pizza pages listed in `public/models/ATTRIBUTION.md`

## Considered and rejected

### Sketchfab photoreal dinosaurs (various)

- Typical license: CC BY-NC or Standard (paid)
- Quality: often higher fidelity
- Status: **rejected**
- Reason: noncommercial terms, unclear redistribution, or franchise-adjacent sculpts

### DailyArt Stegosaurus and similar Sketchfab animals

- License: CC Attribution-NonCommercial
- Status: **rejected**
- Reason: NC forbids the commercial prototype / campaign use case

### ArachnoBoy Velociraptor

- License: CC BY-NC
- Notes: explicitly Jurassic World/Park inspired
- Status: **rejected**

### Smithsonian / museum scan libraries

- License: often CC0
- Animation: none / unrigged
- Status: **rejected for this build**
- Reason: static scans cannot satisfy idle animation or grounded life-scale motion

### MIT 8th Wall engine (`8thwall/8thwall` packages/engine)

- Not an art asset, but evaluated as a runtime
- Status: **rejected for AR**
- Reason: SLAM / world tracking is only in `@8thwall/engine-binary`

## Campaign imagery

- Home hero and menu texture: Higgsfield Nano Banana 2 (`nano_banana_flash`) after Nano Banana Pro remained queued
- Constraint: no logos or interface type in the image
- If a generation includes stray letters, it is regenerated before shipping
